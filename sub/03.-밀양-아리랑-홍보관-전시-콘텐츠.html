1. LiDAR 인터랙티브 리듬게임

콘텐츠 설명

밀양 아리랑 곡조에 맞추어 플라스틱 공을 프로젝션 화면에 던져 가사를 맞추는 인터랙티브 리듬게임.

  • 프로젝터를 이용하여 게임 화면을 벽면에 투사
  • HOKUYO LiDAR 센서를 이용하여 공이 벽면에 충돌하는 위치를 인식
  • 감지된 위치에 따라 게임 내 상호작용 및 진행 처리

시스템 구성

항목 내용
Input 벽면에 투사된 화면을 향해 플라스틱 공 투척
Sensing HOKUYO LiDAR Sensor
Output Projector
Application Unity

설치 및 콘텐츠 화면


HOKUYO LiDAR 센서를 사용하여 프로젝터가 투사된 벽면에 공을 던지면 상호작용이 발생하며 게임이 진행됨.
