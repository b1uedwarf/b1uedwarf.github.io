1. LiDAR 인터랙티브 콘텐츠

콘텐츠 설명

세계지도에서 국가를 터치하면 해당 국가에서 현재 인기 있는 K-POP 노래 5개를 표시하는 인터랙티브 콘텐츠.
LiDAR 센서를 이용하여 프로젝션 화면에서 사용자의 터치 위치를 인식하도록 구현.

체험 영상

국가별 설치

베트남 | 2022.10.03 ~ 2022.10.07

벨기에 | 2022.10.24 ~ 2022.10.28

태국 | 2022.10.28 ~ 2022.11.01

  • 현장 공간 및 LiDAR 센서 재고 문제로 인터랙티브 콘텐츠 제외
  • 영상 콘텐츠만 설치

홍콩 | 2022.11.15 ~ 2022.11.19

문제 및 해결

LiDAR 센서 설치 위치

문제

  • 베트남 전시에서 LiDAR 센서를 바닥에 설치하였으나, 운영 중 관람객이 센서를 발로 건드리면서 센서 방향이 틀어지는 문제가 지속적으로 발생.

해결

  • 이후 전시부터 LiDAR 센서를 상단에 설치
  • 벨기에 전시부터 변경된 설치 방식 적용

콘텐츠 UI

문제

  • 세계지도에서 국가 간 경계가 명확하게 구분되지 않아 국가 선택이 어려움.

해결

  • 국가별로 서로 다른 색상을 적용하여 경계를 쉽게 확인할 수 있도록 UI 수정

2. Media Art 프로젝터 설치

콘텐츠 설명

Media Art 영상 콘텐츠를 전시 공간의 대형 가벽에 프로젝션하기 위한 프로젝터 설치 및 화면 구성 작업.

  • 현장 프로젝터 배치
  • 투사 영역 조정
  • 다중 프로젝터 화면 정렬
  • Edge Blending

최종 설치

문제 및 해결

베트남

문제

현장 설계도와 실제 공간이 일치하지 않았음.

설계도에 표시되지 않은 계단으로 인해 가벽이 예상보다 가까운 위치에 설치되었고, 프로젝터의 투사거리가 부족하여 화면이 가벽 전체를 채우지 못함.

해결

  • 프로젝터를 최대한 좌우로 배치하여 투사거리 확보
  • 스페어 프로젝터 2대를 추가 투입
  • 다중 프로젝터 Edge Blending을 통해 하나의 화면으로 구성

태국

문제
현장 공간이 좁아 일반적인 위치에서는 프로젝터의 투사거리와 투사각을 확보하기 어려웠음.

해결

  • 프로젝터를 천장에 설치하여 투사거리 확보
  • 가벽 상단을 확장하여 프로젝션 영역 확보
  • Edge Blending을 통해 최종 화면 구성
