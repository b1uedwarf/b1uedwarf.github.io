8. Light Stage Studio

SYSTEM OVERVIEW

변경 전

변경 후

기존 스튜디오의 조명 및 카메라 시스템을 개선하여 더 높은 광량, 자유로운 조명 패턴 제어, 고속 다중 카메라 촬영이 가능하도록 시스템을 재구성.

1. Lighting System

변경 전

  • 낮은 광량
  • OLAT Control 불가
  • White Light만 출력 가능

변경 후

  • LED 출력 향상: 16W → 64W
  • OLAT를 포함한 자유로운 Light Pattern 입력 가능
  • R / G / B / W LED를 이용한 다양한 색상 제어
  • 개별 LED 및 다중 LED 패턴 제어 가능

담당 범위

하드웨어의 실제 제작은 외부 업체에서 진행하였으며, 시스템 설계, 하드웨어 사양 결정, 외주 업체와의 기술 협의, Firmware 및 Software 개발을 포함한 전체 개발 과정을 담당.

  • LED Module 내부 제어 코드
  • Light Signal Transmitter 코드
  • Lighting Control UI
  • Light Pattern Control Logic

2. Multi-Camera System

시스템 구성

Camera 수량
5MP Camera 54대
25MP Camera 30대
Total 84대

변경 전

5MP Camera는 Hardware Specification상 최대 72 FPS 촬영이 가능했으나, 기존 시스템에서는 60 FPS 촬영 시 Frame Drop이 빈번하게 발생.

  • 약 10초 이후부터 안정적인 촬영 유지 불가
  • 데이터 처리 과정의 불필요한 복사 및 연산
  • RAM 사용량 지속 증가
  • Camera 수 증가에 따라 처리 병목 심화

개선

기존 Camera Acquisition Pipeline을 분석하여 데이터 처리 및 Memory Management 과정의 비효율을 개선.

  • Camera Frame 처리 구조 개선
  • 불필요한 Memory Copy 최소화
  • RAM 사용 구조 최적화
  • Camera Resource Management 개선
  • Hardware 성능을 최대한 활용할 수 있도록 Acquisition Pipeline 수정

변경 후

  • 5MP Camera 54대
  • 60 FPS약 55초간 안정적인 촬영 가능

기존 약 10초 수준에서 유지되던 촬영 시간을 하드웨어 변경 없이 약 55초까지 확장하고, 고속 다중 카메라 환경에서 안정적인 데이터 수집이 가능하도록 개선.
