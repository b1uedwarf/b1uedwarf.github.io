Tech Arduino(C++) · Unity(C#)
Objective 커피머신 내부 통신 신호를 분석하고 외부 제어 시스템 구현

SYSTEM OVERVIEW

1. Structure

커피머신 내부의 SPI 통신 신호를 분석하고, 이를 기반으로 Arduino 계열 보드와 외부 Controller를 연결하여 제어할 수 있도록 시스템을 구성.

2. 통신 신호 분석

Digital Oscilloscope를 이용하여 커피머신 내부 SPI 신호를 측정하고 동작 패턴을 분석.

  • 정상 동작 및 오류 발생 시 SPI 신호 확인
  • 커피머신 내부 제어 신호 구조 분석

3. 1차 시스템 구조

ESP32 한 대에서 SPI Read와 MQTT 통신을 동시에 처리하도록 구성.

문제

  • ESP32의 SPI 통신에서 지속적인 Noise 및 신호 단절 발생
  • Arduino Uno에서 동일한 SPI 신호를 수신할 경우 Noise가 발생하지 않음
  • Touch Button 제어에 사용된 Photocoupler가 3.3V 신호를 인식하지 못하고 5V 이상의 신호만 인식

4. 2차 시스템 구조


WiFi 통신을 지원하는 Arduino Uno 계열 보드를 사용하여 SPI와 MQTT를 하나의 보드에서 처리하도록 변경.

문제

SPI Read가 Interrupt 방식으로 동작하면서 처리 중 MQTT 신호가 무시되는 현상 발생.

5. 최종 시스템 구조


SPI 신호 처리와 외부 통신 기능을 분리하여 최종 시스템 구조 구성.

  • SPI 통신 처리
  • 외부 Controller와 MQTT 통신
  • 커피머신 제어 신호 전달
  • Touch Button Control

6. Controller UI


Unity 기반 Controller UI를 통해 커피머신의 기능을 외부에서 제어.
