1. Research Objective

기존 Diffusion 기반 Relighting은 자연스러운 이미지를 생성할 수 있지만 실제 조명 환경과 비교했을 때 다음과 같은 물리적 불일치가 발생할 수 있음.

  • Specular Highlight 위치 불일치
  • Highlight Intensity 차이
  • 비반사 영역의 색상 변화
  • 실제 조명 조건과 다른 광학적 표현

이를 정량적으로 평가하기 위해 실제 OLAT 촬영 데이터와 PBR 기반 Reference를 이용한 Relighting Evaluation Framework를 구성.

2. PBR Optimization Framework

실제 OLAT 이미지와 비교할 수 있는 물리 기반 Reference를 생성하기 위해 다양한 Light Model과 Rendering Equation을 조합하여 최적화.

Light Model

  • Directional Light
  • Point Light
  • Spherical Harmonics (SH)
  • Spherical Gaussians (SG)

Rendering Model

  • Phong
  • Cook-Torrance
  • Subsurface Scattering (SSS)

총 12개의 Light / Rendering 조합을 동일한 조건에서 학습 및 비교.

Optimization Parameter

  • Per-pixel Albedo
  • Roughness
  • Metallic
  • Light Intensity

Held-out OLAT 데이터를 이용해 각 조합의 Rendering 성능을 비교하고, 최종적으로 Point Light + Phong Rendering을 PBR Reference로 사용.

3. Specular Highlight Map

Diffusion Relighting에서 특히 문제가 되는 Specular Highlight를 정량적으로 비교하기 위해 Specular Highlight Map을 구성.

이미지의 Luminance 정보와 Local Contrast를 이용하여 Highlight 영역을 추출하고 Reference와 Prediction의 Specular 영역을 비교.

주요 평가 항목

  • Specular IoU
    • Prediction과 Reference의 Highlight 위치 일치도
  • Specular Intensity Error
    • Highlight 영역의 평균 밝기 차이

이를 통해 단순한 이미지 유사도뿐 아니라 광원이 실제로 만들어내야 하는 반사 특성이 올바르게 생성되었는지 평가.

4. Evaluation Framework

Relighting 결과를 세 가지 관점에서 평가.

Facial Fidelity

  • RGB L1
  • Luminance SSIM

전체적인 얼굴 구조와 밝기 분포의 유사도를 평가.

Specular Consistency

  • Specular IoU
  • Specular Intensity Error

광원에 의해 발생하는 Specular Highlight의 위치와 세기를 평가.

Non-Specular Chromaticity

  • Specular 영역을 제외한 Chromaticity L1

Relighting 과정에서 발생하는 불필요한 색상 변화를 평가.

5. Evaluation Pipeline

실제 OLAT 이미지와 PBR Reference를 기준으로 Diffusion 기반 Relighting 결과를 비교.

  • Ground Truth OLAT
  • PBR Optimization Result
  • Neural Gaffer
  • IC-Light

PSNR, SSIM과 같은 기존 Image Quality Metric뿐 아니라 Specular 및 Chromaticity Metric을 함께 사용하여 Relighting의 물리적 일관성을 평가.
