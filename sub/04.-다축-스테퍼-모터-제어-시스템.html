1. Structure


Tablet Controller에서 MQTT를 통해 Raspberry Pi에 접속하고, Raspberry Pi가 SPI 통신으로 각 TMC5160 Motor Driver를 제어하는 구조.

  • Raspberry Pi의 GPIO 구성에 따라 Motor Driver 및 Motor 추가 가능
  • 여러 Raspberry Pi를 연결하여 제어 가능한 모터 수 확장
  • Tablet Controller에서 생성한 모터 움직임 저장 가능
  • 저장된 움직임을 Controller 없이 서버 명령을 통해 실행 가능

TMC5160 지원 기능

  • 6-Point Acceleration
  • Sensorless Homing
  • StealthChop
  • CoolStep
  • DcStep

4. SPI 통신 문제 및 해결

문제

현장 환경에서 Raspberry Pi와 TMC5160 사이의 SPI 통신에 지속적인 노이즈 발생.
초기에는 통신 케이블 또는 전원 환경을 원인으로 판단하여 다음과 같은 조치를 진행.

  • 케이블 Shield 적용
  • 더 두꺼운 케이블로 교체
  • Power Supply 교체

그러나 문제가 해결되지 않음.

원인 분석

Oscilloscope를 이용하여 SPI 신호를 측정한 결과, TMC5160 Driver와 Raspberry Pi 사이의 접촉 불량으로 인해 노이즈가 발생하는 것을 확인.

해결

기존 연결 케이블을 제거하고 직접 납땜하여 연결한 후 테스트한 결과 SPI 통신 노이즈가 사라지는 것을 확인.
